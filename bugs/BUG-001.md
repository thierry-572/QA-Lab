#BUG-001-Sistema permite tarefa sem nome

##descrição
O sistema permite cadastrar uma tarefa sem informar o nome.

##Requisito relacionado
RNF-001-Validação

##Passos para reproduzir
1.iniciar o Task Manager.
2.Selecionar de opção criar tarefa.
3.não informar nenhum nome.

##Resultado esperado
O sistema deve impedir o cadastro e informar que o 
nome da tarefa é obrigatório.

##Resultado obtido
O sistema permite continuar sem informar nome.

##Severidade
Baixa

##Status
Aberto

##investigação
O problema ocorre porque o sistema recebe a entrada do usuário e não verifica
se a variável "tarefa" está vazia antes de continuar.

##correção proposta
Adicionar uma validação ultilizando um "if" após a leitura da tarefa.
Se a tarefa estiver vazia,o sistema deve impedir o cadastro e 
informar ao usuário que o nome da tarefa é obrigatório.
