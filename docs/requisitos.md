#QA Lab-Task Manager

##RF-001-Criar tarefa
o sistema deve permitir que o usuário crie uma tarefa informando seu
nome.
 
##RF-002-Listar tarefas
O sistema deve permitir visualizar todas as tarefas
cadastradas.

##RF-003-Concluir tarefa
O sistema deve permitir marcar uma tarefa como concluída.

##RF-004-Excluir tarefa
 sistema deve permitir excluir uma tarefa.

##RNF-001-Validação
O sistema não deve permitir o cadastro de uma tarefa sem nome.
